커밋과 푸시

커밋 commit
  • 내 컴퓨터 안에 저장 기록을 남김
  • 게임의 세이브 포인트
푸시 push
  • 그 기록을 GitHub 보관소로 보냄
  • 세이브 파일을 클라우드에 업로드
한 줄 요약 — 커밋 = 저장, 푸시 = 업로드

6부 · 꼭 알아야 할 것

RLS — 공책의 자물쇠

  • RLS = 누가 무엇을 할 수 있는지 정하는 규칙
  • 오늘 규칙: 누구나 읽기·쓰기 O, 고치기·지우기 X
  • RLS가 꺼져 있으면: 주소만 알면 누구나 전부 지울 수 있음
  • Table Editor에서 표 옆에 RLS disabled 경고가 없어야 정상
⚠️ 학생 실명·연락처 같은 개인정보는 넣지 않기

심화 B

Supabase MCP

“MCP = Claude에게 그 서비스를 직접 다루는 손을 달아 주는 방식”

맡기는 방법 두 가지

CLI vs MCP

CLI — 심화 A
  • Claude가 터미널에 명령을 입력
  • 무엇을 했는지 화면에 그대로 보임
MCP — 심화 B
  • Claude가 서비스에 직접 연결
  • 설치 없이 로그인만
둘 다 “Claude에게 맡기는 방법” — 서비스마다 편한 쪽을 고르면 됨

심화 B · 단계 ①

프로젝트 ID 확인

Supabase → Project Settings → General → Project ID 복사
주소창의 supabase.com/dashboard/project/○○○○ 뒤 글자와 같아요
이 ID로 Claude가 이 프로젝트 하나만 만지게 제한해요

심화 B · 단계 ②

읽기 전용으로 연결

Claude를 끄고(Ctrl+C 두 번) 터미널에서 — 프로젝트ID 자리를 바꿔서

PowerShell
claude mcp add --scope project --transport http supabase "https://mcp.supabase.com/mcp?project_ref=프로젝트ID&read_only=true"
claude 실행 → /mcp → supabase → Authenticate → 브라우저에서 허용

read_only = Claude가 보기만 하고 바꾸지 못함

✋ 따라 하기 · 심화 B ③

물어보기 (읽기 전용)

Claude에게 입력
Supabase MCP로 내 데이터베이스에 어떤 테이블이 있고 글이 몇 개 쌓였는지 알려줘
Claude에게 입력 — 핵심
Supabase 보안 점검(advisors)을 돌려서 문제가 있으면 쉽게 설명해줘
RLS 빠뜨린 곳을 Claude가 먼저 찾아 줘요

심화 B · 단계 ④

쓰기 권한 열고 기능 추가

PowerShell — 연결 지우기
claude mcp remove supabase
PowerShell — read_only 없이 다시 연결
claude mcp add --scope project --transport http supabase "https://mcp.supabase.com/mcp?project_ref=프로젝트ID"
claude 실행 후 Claude에게 입력
방명록 글마다 좋아요 버튼을 추가해줘. 테이블 변경은 Supabase MCP로 하고, 코드 수정 후 커밋하고 푸시해줘.
⚠️ 쓰기 권한이 있으면 데이터를 지울 수도 있어요 → 실행 전에 보여주는 SQL을 읽고 허락하기
