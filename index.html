오늘의 도착점

오늘 끝나면 이렇게 됩니다

  • 내 컴퓨터에서 claude라고 치면 Claude가 켜진다
  • Claude가 내 폴더에 파일을 직접 만든다
  • 내가 만들고 싶은 교실 도구의 설계서가 폴더에 저장되어 있다
  • 다음 주, 그 설계서로 진짜 웹앱을 만든다

무엇이 다른가요?

채팅 Claude vs 클로드코드

채팅 Claude
  • 브라우저에서 대화
  • 결과를 복사해 와야 함
  • 파일은 내가 만듦
클로드코드
  • 내 컴퓨터 안에서 일함
  • 폴더를 읽고 파일을 직접 만들고 고침
  • 명령도 대신 실행
한 줄 요약 — “내 컴퓨터에 들어와 일하는 조교”

터미널이 처음이라면

검은 화면, 무섭지 않습니다

  • 터미널 = 마우스 대신 글자로 컴퓨터에게 말하는 창
  • 오늘 외울 명령어는 사실상 1개: claude
  • 나머지는 전부 복사-붙여넣기
  • 틀려도 컴퓨터 안 망가짐. 창 닫고 다시 열면 됨

5부 · 범위 정하기

좋은 크기 vs 큰 크기

좋은 크기
  • 화면 1~2개
  • 하는 일 1가지
  • 로그인 없음(또는 이름만)
큰 크기
  • 교사·학생·학부모 각각 화면
  • 알림·채팅
  • 성적 처리
원칙: 2시간 안에 만들 수 있는 크기로. 작게 성공하고 키우기
